# 서울 구별 카페 현황 (2026년 3분기 스냅샷) 

![Coffee GIF](https://media.giphy.com/media/3nbxypT20Ulmo/giphy.gif)

2026년 3분기 기준 서울 25구의 카페 수와, 전체 상가에서 카페가 차지하는 비중을 비교했다. 

[분석 노트북 보기](seoul_commercial_v4.ipynb)

## 배경과 질문 

서울에서 카페 창업을 고려하는 창업자의 관점에서 서울의 현재 상권 현황을 파악하고 싶었다. 

- 구마다 어떤 업종이 제일 많은가? (이를 통해 각 구의 성격을 파악하고자 하였다.)
- 구별 카페 비중은 서울 평균보다 높은가, 낮은가?

우선 서울 전체의 카페 평균 비중을 구했다. 그다음 구별로 상위 업종과 그 비중을 살펴보고, 같은 구에서 카페가 차지하는 비중을 계산하여 비교했다. 

## 데이터

- 출처: [공공데이터포털](https://www.data.go.kr/index.do), 소상공인시장진흥공단_상가(상권)정보
- 기준: 2026년 9월 30일
- 규모: 552,422행, 39열 (서울시 데이터)
- 사용한 컬럼: `상가업소번호`, `상호명`, `지점명`, `상권업종소분류명`, `시군구명`, `법정동명`
- 원본 링크: https://www.data.go.kr/data/15083033/fileData.do (폴더 내 서울시 데이터 선택)

## 방법

1. 필요한 컬럼 6개만 불러왔다.
2. 상호명과 지점명을 합쳐서 '상호/지점' 컬럼을 새로 만든 뒤, 상호명과 지점명을 삭제했다.
3. '상가업소번호' 기준으로 중복을 제거했다.
4. 구별, 업종별 상가 수를 세고, 구별 전체 상가 수 대비 업종 비중(%)을 계산했다.
5. 카페만 따로 구별로 세어 위 표에 붙이고 (merge), 구내 카페 비중을 계산했다.
6. 서울 전체 카페 비중(서울 카페 수 / 서울 전체 상가 수)을 기준값으로 정하고, 구별 카페 비중과 비교했다.
7. 프랜차이즈는 '상호/지점'에 '점'이 들어간 카페로 추정했다.

## 주요 결과 

- 서울 전체 카페 수: 20,575개
- 서울 전체 카페 비중(기준값): 3.861% 
- 마포구, 종로구, 용산구는 구내 카페 비중이 서울 평균보다 높았다. (마포구 5.44%)
- 강남구는 2.89%로 가장 낮았고, 금천구와 서초구도 낮은 편이었다.
- 이 세 구는 경영 컨설팅업 비중이 높았고(강남구 10.25%, 금천구 9.58%, 서초구 7.94%) 전체 상가 수가 커서 카페 비중이 낮게 나왔을 수 있다.
- 프랜차이즈로 추정되는 카페는 서울 전체 카페의 약 32.5%였다.

## 한계

- 상가 수 비중만으로는 카페 수요를 알 수 없다. 사무실이 많은 구는 전체 상가 수가 커서 카페 비중이 낮아 보일 수도 있다.
- 프랜차이즈를 '점' 포함 여부로 추정해서 실제와 다를 수도 있다.
- 구 단위 분석이라 같은 구 안의 동별 차이를 볼 수 없다.
- 한 시점의 스냅샷이라 개업과 폐업 추이를 알 수 없다.
